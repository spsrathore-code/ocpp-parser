User Guide - Extended Tool

1. OCPP Simulator Tab

This tab contains the original OCPP 1.6-J simulator functionality with all the features from the base tool.

2. Transaction Flow Simulator Tab

🔄 NEW FEATURE: Simulate complete OCPP transaction flows with realistic timing based on CMS log data:

  • Upload CMS Logs: Select Excel files containing CMS logs with transaction data.
  • Parse for Flow Simulation: Extract complete message sequences with timing information.
  • Select Transaction: Choose specific transactions to simulate with full message flow.
  • Playback Speed Control: Adjust simulation speed from real-time to instant playback.
  • WebSocket Integration: Optionally connect to live CSMS for real message sending.
  • Timeline Visualization: Real-time timeline showing message flow progression.
  • Flow Control: Start, pause, stop, and reset simulation with detailed progress tracking.
  • Message Logging: Complete log of all simulated messages with timing details.
  • Sample Data: Built-in sample transaction for testing and demonstration.

Key Benefits: This feature enables complete recreation of charging scenarios from logs, perfect for testing, debugging, and site behavior analysis. It maintains original timing relationships between messages for realistic simulation.

3. CMS Log Parser Tab

This new tab allows you to parse CMS logs and analyze meter values:

  • Upload CMS Logs: Select and upload your CMS logs Excel file.
  • Parse Logs: Click "Parse Logs" to extract meter values and transaction data.
  • View by Transaction: Select specific transactions or view all transactions.
  • Export Results: Export parsed meter values to Excel format.

4. Meter Values Analysis

The tool provides detailed analysis of meter values including:

  • Energy consumption tracking (kWh)
  • Power readings (kW)
  • Voltage and current measurements
  • State of Charge (SoC) progression
  • Temperature monitoring
  • Transaction context (Begin, Periodic, End)

4. Dynamic Graphs

For individual transactions, the tool provides interactive graphs:

  • Current Import by Phase: L1, L2, L3 current vs time
  • Power and SoC: Power delivery and State of Charge vs time
  • Power Comparison: Outlet vs Inlet power in kW vs time
  • Temperature Monitoring: Body, Inlet, and Outlet temperatures vs time
  • EV Parameters: Power, Current, Voltage, and SoC vs time

Each graph includes dropdown selectors to view individual parameters or all parameters together.
